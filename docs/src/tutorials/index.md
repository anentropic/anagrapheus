# Tutorials

These lessons teach anagrapheus by building and running something. Work through them in order: the first gets one exchange recording and replaying in a few minutes, and the second takes you through a full negotiation that uses every layer of the library.

- **[Getting Started: Record and Replay an Agent](getting-started.md)**: Record a two-agent exchange, save it to a file, and replay it in a new process without calling the model.
- **[Touring the Negotiation Example](negotiation-example.md)**: Run the repository's four-round EU and UK negotiation, then inspect its log, beliefs, chronicle, prompts and replay.

Start with Getting Started if pinning and replay are new to you. If you already know them, or you came here from the negotiation example, go straight to the tour.
